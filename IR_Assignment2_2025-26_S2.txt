Objective
This assignment is open-ended and does not prescribe a specific application domain or use case. Students are expected to choose a use case that is most relevant to their work, interests, or specific area of application. Students shall apply Information Retrieval concepts to any suitable dataset or collection, demonstrating the complete IR lifecycle while integrating the concepts mentioned below into a single, cohesive Streamlit-based system.
1.	Task Breakdown
Executing the Assignment on BITS Lab portal - 1 Mark
A. Streamlit-Based End-to-End Workflow
Develop a professional Streamlit application that includes:
•	Dashboard 
•	Search interface 
•	Crawling interface 
•	Index management 
•	Ranking visualization 
•	Recommendation panel 
•	Evaluation dashboard 
•	Performance analytics
The complete workflow must be executable through the Streamlit front end only. Students should not show provide backend code or static notebook outputs.
B.Requirements
•  Acquire information from one or more heterogeneous sources through web crawling, publicly available datasets, APIs, or a combination of these. 
•  Support configurable crawling depth and multiple seed sources. 
•  Handle duplicate URLs and duplicate documents. 
•  Store extracted metadata separately from document contents.




C. Text Preprocessing and Mining
•	Develop a scalable text mining framework that transforms raw textual data into structured feature representations through preprocessing, feature engineering, and statistical analysis.
•	The framework should support keyword extraction, document profiling, document classification, comparative analysis of different preprocessing and feature extraction strategies. 
•	Appropriate visualizations should be provided to interpret corpus characteristics, and feature distributions.
D. Web Searching:
•	Develop an intelligent web search module that supports diverse query processing, ranked document retrieval, and efficient search over indexed collections. 
•	The system should provide relevant search results with appropriate metadata and incorporate advanced query optimization techniques wherever applicable.
•	Use any of the algorithm (Page Rank/HITS) and display how ranking is important
E. Recommender System
Develop a recommendation module. The recommender should support one or more of the following:
•	Content-based recommendation 
•	Collaborative recommendation
•	Hybrid recommendation
Display Top-K recommendations together with similarity scores.
F. Evaluate the effectiveness of the retrieval system using appropriate Information Retrieval metrics such as,
•	Precision 
•	Recall 
•	F1-score 
•	Precision@K 
•	Recall@K 
•	MAP 
•	MRR 
•	NDCG 
Provide comparative analysis using tables and visualizations.
G. Inference and Discussion *** This section is compulsory.***
Students must provide clear inferences in the report for every task. You should answer: 

1.   Suppose your system retrieves highly relevant documents but ranks them poorly. Identify the possible causes and propose improvements to the ranking strategy.
2. If duplicate or near-duplicate documents exist in the corpus, how would they affect indexing, ranking, recommendation, and evaluation? Suggest methods to mitigate these effects.
3. Compare the effectiveness of content-based recommendation and Collaborative -based recommendation in an Information Retrieval system. Under what scenarios would each approach be preferable?
4.  Discuss how the integration of crawling, text mining, indexing, search, ranking, and recommendation contributes to the overall effectiveness of an end-to-end Information Retrieval system.
 5.    Based on the results obtained provide your learnings clearly.
